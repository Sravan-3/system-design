# Real-World Systems

## Cassandra

Uses:

* consistent hashing
* virtual nodes
* replication
* quorum reads/writes

Designed for:

* high availability
* massive scalability

---

## DynamoDB

Inspired by Amazon Dynamo.

Uses:

* partitioning
* replication
* eventual consistency

---

## Redis Cluster

Uses hash slots for partitioning.

Supports:

* distributed caching
* automatic failover

---

## Akamai CDN

Uses distributed routing and hashing techniques for edge distribution.

---

## Kafka

Uses partition-based distribution.

Consumers scale using partitions.
